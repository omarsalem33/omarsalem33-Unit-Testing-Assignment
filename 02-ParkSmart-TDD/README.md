# ParkSmart TDD

The solution is in `ParkSmart/` and contains Domain, Application, Infrastructure, ConsoleApp, UnitTests, and ArchitectureTests projects. The calculator covers S1-S10. Run the full suite with:

```powershell
dotnet test ParkSmart/ParkSmart.slnx
```

The app receives a duration in whole minutes and reports the car fee in EGP. Unit tests include the stage examples and boundary cases. The ArchitectureTests project checks assembly dependency direction and the test-class suffix convention.
